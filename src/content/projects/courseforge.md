An open-source MCP server with 20+ tools and a Common Cartridge toolkit. Give Claude Code a syllabus and it builds modules, pages, assignments and quizzes in one import. Everything stays unpublished until the teacher has looked at it, because nobody wants a robot publishing their course at 3am.
